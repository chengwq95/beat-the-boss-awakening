# 暴打老板：打工人觉醒 · Beat the Boss Awakening

一款中文点击放置小游戏。疯狂点击老板、积攒怒气、命中弱点、使用应急道具，并在“辞职周目”里用永久加成越打越强。

## 在线访问

[beat-the-boss-awakening.pages.dev](https://beat-the-boss-awakening.pages.dev/)

## 内容

老板关卡、怒气技能、弱点攻击、职场军火库、应急道具、随机宝箱、晋升奖励、狂暴关、辞职周目、自动存档与离线收益。

## 玩法

- 点击老板造成伤害并获得奖金，购买装备提升点击伤害、自动伤害、暴击率和额外收益。
- 积攒怒气后释放连续欧拉、加班爆发或劳动仲裁，分别强化点击、提升自动伤害或直接扣除老板生命。
- 战斗中会随机出现弱点，命中后造成高额伤害；老板也会读条释放技能，需要及时打断。
- 每 5 关进入限时狂暴关，突破后可以选择永久增强奖励。
- 应急道具可临时提升点击、增强自动伤害或冻结时间，适合处理卡关和狂暴倒计时。
- 达到第 15 关后可开启辞职周目，重置关卡与商店，换取永久全局加成。

## 特性

- 零依赖、单文件、可离线运行
- `localStorage` 自动存档，并兼容旧版存档键
- Web Audio API 实时生成点击、暴击、技能、购买与胜利音效
- 响应式布局，支持鼠标、触控、键盘焦点与 ARIA 标签

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装依赖或启动服务。
